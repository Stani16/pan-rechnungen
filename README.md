# PAN Rechnungen

Rechnungs-App für PAN Transporte (Neuss). Läuft im Browser auf iPhone und Laptop.

- Daten liegen in einer Supabase-Datenbank, Zugang nur mit Login und Freischaltung.
- `config.js` enthält nur die öffentliche Projekt-Adresse und den öffentlichen Schlüssel der Datenbank. Geheime Daten sind nicht in diesem Repository.
